# MatrixGame r42. A/B записи журнала

**SOFTWARE PASS / HARDWARE PENDING.** В архиве одна Interactive NRO.
Режим задаётся при запуске и записывается в `metadata/journal_mode`.

| Аргумент | Режим |
| --- | --- |
| `--journal=sync` | A. Запись, flush и sync каждой строки. Запуск без аргументов тоже выбирает A. |
| `--journal=batch` | B. Те же строки, буфер до 64 КиБ во время видимой карты. |

В B буфер записывается при нехватке места для следующей строки, на границе
кадра после одной секунды или непосредственно перед контрольным замером.
BOOT, Init, переход и teardown пишутся синхронно. Ошибка или штатная
остановка также сбрасывает накопленные строки. Внезапное прерывание может
оставить на microSD только последний синхронизированный пакет. Любой отказ
записи, flush или sync отмечается как ошибка, а запуск завершается с кодом
11, если журнал потерял работоспособность.

## Два запуска через NetLoader

В hbmenu используйте Application Mode с полной памятью приложения. Оставьте
существующие игровые файлы r41 на прежних местах. Запуск использует
`/switch/matrixgame-diag/game/` для трёх оригинальных файлов MatrixGame и
`/switch/space-rangers-hd-a-war-apart/game/` для Rangers DATA, CFG и
INSTALL-файлов. Ресурсы и сохранения в архив не входят.

Откройте NetLoader кнопкой Y. Укажите фактический путь к распакованной
NRO и отправьте **A**. После автоматического выхода снова откройте
NetLoader и отправьте **B**.

```powershell
$nxlink = 'C:/devkitPro/tools/bin/nxlink.exe'
$nro = 'D:/путь/к/распакованному-r42/matrixgame-r42-journal-ab.nro'
& $nxlink -a 192.168.2.225 -p matrixgame-r42-journal-ab.nro $nro --args '--journal=sync'
# После завершения A и повторного открытия NetLoader
& $nxlink -a 192.168.2.225 -p matrixgame-r42-journal-ab.nro $nro --args '--journal=batch'
```

Для обоих запусков оставьте видимую карту без ввода и дождитесь
120-секундного лимита после Init. Используйте одинаковый портативный режим
или док и одинаковые настройки. При необходимости Minus+Plus завершает
Interactive досрочно. Пришлите `run.jsonl` и доступные `.bgra` из двух
новых каталогов `/switch/matrixgame-diag/logs/<run-id>/`.

Сравнение использует временные метки `original_loop_frames_presented` на
кадрах 60 и 240. Профиль I/O снят перед записью каждой из этих отметок,
после обязательного сброса ожидающих записей. `profile.journal.calls`
означает физические вызовы записи, `journal_io_phases` содержит отдельно
`write_calls`, `flush_calls`, `sync_calls`, время стадий и число успешно
синхронизированных строк `durable_rows`. Сверяются также draw, отправки,
drains, интервалы ожидания GPU, непрерывный seq, `journal_close`, код
выхода и BGRA. Два запуска используют одинаковый Build ID и SHA256 NRO.
