# E2E-5.16 — проверка, когда Switch снова будет доступна

Сейчас аппаратный прогон не требуется. Все аппаратные дефекты остаются
HARDWARE PENDING. Настройки Atmosphère, HOC/sys-clk и частоты не менять.

1. Сохранить на ПК копию игровой папки, настроек и сохранений.
   Из этого ZIP скопировать `switch/` на SD. Запускать именно
   `SpaceRangersHD-perf516.nro` прежним рабочим способом в application mode.
   ELF из `debug/` нужен только для разбора ошибок на ПК.
2. Сверить SHA-256 NRO по `SHA256SUMS`, а короткий `build_git` в
   `logs/perf515-stage.log` — с `source_commit` из `manifest.json`.
   Имена журналов `perf515` сохранены для совместимости анализаторов.
3. Для фонов и карты взять `perf-mode.txt` из `mode-examples/basic/`,
   `scene-mode.txt` из `mode-examples/scene-on/` и положить рядом с NRO.
   После запуска пройти генерацию → персонаж → станция → карта → меню →
   подтверждение выхода → отмена → карта. Отметить первый чужой фон.
   На карте сделать один ход и приказ перемещения: отдельно проверить дату,
   движение объектов и отклик управления. Снять короткое видео дефекта.
4. На копии данных сохранить игру после перелёта с латинским и кириллическим
   именем, штатно выйти, перезапустить NRO и загрузить оба сохранения.
5. Для аркады поставить `scene-mode.txt=off`, оставить `basic` и перезапустить
   игру. В одном бою 60–90 секунд двигаться, стрелять, дождаться столкновений
   и взрывов. Проверить отзывчивость и скорость игрового времени.

После каждого отдельного запуска, до следующего, скопировать на ПК весь
`sdmc:/switch/space-rangers-hd-a-war-apart/logs/`, включая `.1`, CSV и PPM.
Снимки ограничены 48 файлами на запуск; пропуски отмечаются `image_dropped`.
После проверки сохранений добавить копию `config/Save/` со всеми `.sav`,
`.tmp`, `.bak`, recovery-файлами и игровой `.log`, если она появилась.
Приложить видео, имя NRO, выбранные basic/detail/off и scene on/off.
Системное CSV-логирование настраивать не нужно.

Анализ на ПК из папки `analysis/`:

```text
python e2e515_perf_analyze.py --game COPIED_LOGS/perf515.csv --stage-log COPIED_LOGS/perf515-stage.log --screen 21 --out NEW_ARCADE_ANALYSIS
python e2e515_scene_analyze.py --log COPIED_LOGS/perf515-stage.log --images COPIED_LOGS --out NEW_SCENE_ANALYSIS
```

Снимки показывают CPU-буфер перед SDL upload, а не GPU readback. Изменение
одного общего хэша или подсказки не доказывает обновление игрового мира.
Отключить диагностику можно файлами `perf-mode.txt=off` и `scene-mode.txt=off`;
пользовательские настройки и сохранения удалять не нужно.
