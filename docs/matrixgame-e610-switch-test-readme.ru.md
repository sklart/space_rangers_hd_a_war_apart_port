# MatrixGame E610 — два ручных запуска на Switch

**SOFTWARE PASS / HARDWARE PENDING.** Это отдельные homebrew-диагностики на
libnx/deko3d. Аппаратных результатов этих двух NRO пока нет. SHA исходников,
build ID и SHA256 бинарников находятся в manifest.json и build-info.json.
SHA256SUMS.txt позволяет проверить все файлы пакета на компьютере.

## Копирование

Скопируйте только два NRO из архива, не заменяя основную NRO или прежние тесты:

```text
<microSD>/switch/matrixgame-e610-test/matrixgame-e610-quick-smoke.nro
<microSD>/switch/matrixgame-e610-test/matrixgame-e610-interactive.nro
```

Игровые ресурсы в архив не входят. Уже подготовленные для E604 каталоги можно
использовать без повторного копирования. Приложение читает:

```text
<microSD>/switch/matrixgame-diag/game/DATA/robots.pkg
<microSD>/switch/matrixgame-diag/game/CFG/robots/data.txt
<microSD>/switch/matrixgame-diag/game/CFG/robots/iface.txt
<microSD>/switch/matrixgame-diag/rangers/install.txt
<microSD>/switch/matrixgame-diag/rangers/install_russian.txt
<microSD>/switch/matrixgame-diag/rangers/CFG/...
<microSD>/switch/matrixgame-diag/rangers/DATA/...
```

Для game используются robots.pkg из своей тестовой копии игры и оригинальные
текстовые CFG/robots из закреплённого MatrixGame upstream. Их контрольные суммы
приведены в manifest.json. Для rangers нужны согласованные install-файлы,
CFG и DATA из одной собственной легальной копии игры: в частности CFG/Main.dat,
CFG/CacheData.dat, CFG/Rus/Lang.dat и все packages, указанные в install.txt и
install_russian.txt, включая звук/музыку. Не копируйте сохранения и пользовательские
настройки. Не заменяйте неизвестные существующие ресурсы автоматически.

## Запуск через hbmenu

Используйте уже настроенный hbmenu в **Application Mode**, с памятью приложения.
При стандартном application override это вход с удержанием R во время запуска
установленной игры/приложения; при иной конфигурации используйте её способ входа.
Ничего устанавливать или менять в системном ПО для этого пакета не требуется.
Album/Applet Mode не подходит: программа проверяет applet type и откажется
до GPU-инициализации. На всех стадиях память может оказаться недостаточной;
её лимит и фактическое использование записываются в журнал.

В hbmenu откройте switch/matrixgame-e610-test, выберите нужную NRO и нажмите A.
Отпустите кнопки после запуска. Сборки используют уникальный каталог для каждого
прогона; основная игра и её сохранения не открываются для записи.

## Запуск №1 — Quick Smoke

Выберите matrixgame-e610-quick-smoke.nro (название в hbmenu: MatrixGame diagnostic). Не управляйте боем: наблюдайте до
автоматического возврата в hbmenu либо первого сбоя. Последовательность:

1. A: native/deko3d, настоящий BC1 draw/readback и gamma smoke.
2. B: настоящий CGame::Init и загрузка карты.
3. C: четыре завершённых видимых кадра карты. Загрузочные transition frames
   в эти четыре не входят; счётчик растёт только после настоящего Present.
4. D: SaveResult в память, cleanup и восстановление device/window state.

Синтетическая картинка smoke не считается кадром MatrixGame. Штатный успех
возможен только при реальном выполнении стадий. B или Plus отменяют quick-тест
на ближайшей безопасной границе; такая отмена — не PASS. Есть кооперативный
лимит 120 секунд; блокирующий вызов SDK нельзя принудительно пропустить.

## Запуск №2 — Interactive, до 120 секунд после Init

Выберите matrixgame-e610-interactive.nro (MatrixGame diagnostic manual). После успешной загрузки карты проверьте
изображение, плавность, курсор, кнопки, меню/паузу, камеру и — если доступны —
выделение, приказы движения, вход в робота, звук и стрельбу.

| Кнопка | Назначение в этой standalone-сборке |
| --- | --- |
| Правый стик | Указатель |
| A / B | Левый / правый клик |
| D-pad | Прокрутка камеры |
| L / R | Поворот камеры |
| X | Вход/выход робота |
| Левый стик | Движение управляемого робота |
| ZR / ZL | Огонь / Shift |
| Y | Отмена приказа |
| Plus | Оригинальное меню; паузу проверьте в пределах доступного UI |
| Minus + Plus | Штатный запрос завершения диагностики |

Не удерживайте exit chord при старте: для выхода отпустите и нажмите сочетание
заново. До доступности робота или действий соответствующие пункты отмечайте
«недоступно», не PASS. Сочетание Minus+Plus проверяется на безопасных границах;
при синхронном Init оно может обработаться только после его возврата.
Лимит интерактивной стадии отсчитывается после Init. Сам Init имеет отдельный
кооперативный лимит. При штатном автоматическом лимите возможна запись Timeout;
для проверки пользовательского выхода завершите через Minus+Plus раньше лимита.
Если первый запуск сломался рано, второй может подтвердить ту же границу;
не пытайтесь обходить её или менять ресурсы между двумя запусками.

## Что охватывается

Это **standalone CGame::Init/Draw**, native graphics и MatrixGame HID mapping.
Используются текущие исправления E610 физического ввода/held-state. Отдельные
RangersNativeInput/UiContext/CallerPresentation/Campaign owners этой точкой
входа не создаются. Поэтому пакет не доказывает UI-переход Galaxy → Gov → бой,
награду, возврат в Galaxy или естественную победу. Наличие символа в ELF само
по себе не означает его вызов; retained_symbols отражены в manifest.json.

## Журналы и результаты

Программа создаёт отдельный каталог запуска под:

```text
<microSD>/switch/matrixgame-diag/logs/<run-id>/
  run.jsonl
  smoke.bgra, gamma-smoke.bgra, original-first.bgra  # если стадии достигнуты
  ... метаданные readback ...
  output/                  # частный вывод MatrixGame, включая миникарту
  output/Screenshots/      # если создан screenshot
  rangers-user/            # частный runtime host, не ваши сохранения
```

Readback .bgra — сырые диагностические кадры, не PNG. Можно дополнительно сделать
фото экрана или короткое видео. Если среда уже создаёт crash reports, приложите
соответствующие новые файлы из atmosphere/crash_reports или atmosphere/fatal_errors;
сама диагностика эти каталоги не создаёт и системную конфигурацию не меняет.

После двух запусков скопируйте на компьютер только их два новых каталога журнала,
фото/видео и соответствующие crash reports. Упакуйте их отдельно и передайте в
этот чат вместе с таблицей. Игровые DATA/CFG и свои сохранения не присылайте.
При отсутствии журнала укажите это и приложите фото ошибки/экрана hbmenu.

| Проверка | Quick | Interactive |
| --- | --- | --- |
| Запуск / изображение smoke | не проверено | не проверено |
| Init / загрузка карты | не проверено | не проверено |
| Реальные кадры карты | не проверено | не проверено |
| Курсор / кнопки / меню / пауза | не применимо | не проверено |
| Камера / робот / движение / стрельба / звук | не применимо | не проверено |
| Возврат в hbmenu / Minus+Plus | не проверено | не проверено |
| Сбой, артефакты, последний видимый этап | — | — |

До получения этих наблюдений всё аппаратное покрытие остаётся HARDWARE PENDING.
Следующие изменения планируются после анализа именно этих запусков.
