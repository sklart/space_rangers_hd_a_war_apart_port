The first `git apply -C <disposable-directory>` attempt returned success without changing the copied source because Git resolved the enclosing repository as its worktree. The builder now applies each patch with `--directory=<disposable-directory>` and asserts a patched GR_Main marker. The earlier link result was repeated after correcting this build-integrity error; it is not used as proof for the patched renderer.

The latest exact compiler/link/audit output and source counts are in `e2e-build-report.json`. The seventh supplied Switch log reaches `global UI` but does not establish completion or a menu. Local NRO and supplied log hashes are recorded in [`e2e1-complete-game-main-loop.md`](e2e1-complete-game-main-loop.md).

The E2E-WIN32 source sweep now resolves the statically visible Win32 surface through a central registry. Its final local ARM64 build links with zero undefined symbols, both manifests have `UNKNOWN=0`, and all startup-required classifications are implemented. Thus E2E-002 and E2E-008 have software fixes and a new candidate NRO, but the previous hardware failure remains the last observed runtime result until that candidate runs. DLL strings in the ELF are now classified as module names or static-library identifiers rather than treated as automatic link failure; see [`e2e-win32-compat.md`](e2e-win32-compat.md).
