## Цепочка Init и действительное покрытие NRO

Существующая standalone entry создаёт diagnostic environment и GPU smoke,
RangersHostSession с настоящими data/audio/music/callback services,
NativeInitRuntime с оригинальным CGame::Init, SwitchWindow и DekoDevice.
Далее предусмотрены загрузка карты, оригинальные Takt/Draw, результат в памяти
и cleanup. Native output-folder provider, CFile и владение ресурсами остаются
частью текущих исходников; диагностический вывод отделён от игровых ресурсов
и пользовательских сохранений. На Switch эта цепочка пока не исполнена.

| Компонент | Что установлено для двух новых ELF |
| --- | --- |
| SwitchInput::Poll и router cursor warp | Сохранены линкером; вызываются standalone вводом |
| Prime/held gates и восстановление позиции курсора | Используются общим путём Poll/focus/attach; физический эффект не проверен |
| RangersNativeInput / RangersUiContext | Не создаются standalone entry, удалены из ELF |
| CallerPresentation / NativeRangersCanvas | Не создаются, удалены из ELF |
| Campaign session / GR_WinMessage | Не сохранены в этих ELF, исполнения нет |
| CancelHeldInput как reset владельца UI | Не сохранён в этих ELF; не выдаётся за проверенный этим пакетом |

Оригинальный dependency archive включает E610, однако это не означает вызова
всех его компонентов. Пакет не проверяет Galaxy/Gov → Robot::FRun → Galaxy/Gov.
Единая native Campaign/Gov entry остаётся недостающим компонентом. Windows
доказательство поражения/возврата не переносится на standalone Switch.

## Два ручных запуска

Полная [инструкция](../docs/matrixgame-e610-switch-test-readme.ru.md) совпадает
с README.ru.md внутри ZIP: пути ресурсов, доступная память, кнопки, этапы,
выводимые изображения, журналы и передача диагностических файлов.

1. Скопировать две NRO в `<microSD>/switch/matrixgame-e610-test/`.
   Ресурсы своей легальной копии оставить в подготовленных `game` и `rangers`
   под `<microSD>/switch/matrixgame-diag/`, как указано в инструкции.
   Запускать через имеющийся hbmenu в Application Mode с полной памятью.
2. Quick Smoke: наблюдать до автоматического завершения или первого сбоя.
   Контракт требует Init, карты и четырёх настоящих видимых кадров; отмена
   не считается PASS. При блокировке не пропускать стадию принудительно.
3. Interactive: после Init проверить курсор/кнопки, меню/паузу, камеру,
   доступные робот/звук/стрельбу. До 120 секунд; штатный выход Minus+Plus.
4. Передать папки двух новых запусков из
   `<microSD>/switch/matrixgame-diag/logs/<run-id>/`, фото/наблюдения и при
   наличии crash reports. Игровые ресурсы и сохранения передавать не нужно.

| Аппаратный пункт | Quick | Interactive |
| --- | --- | --- |
| Init / карта / реальное изображение | NOT RUN | NOT RUN |
| Четыре видимых кадра / артефакты / зависания | NOT RUN | NOT RUN |
| Физический HID / меню / пауза / камера | NOT RUN | NOT RUN |
| Робот / звук / стрельба, если доступны | NOT RUN | NOT RUN |
| Штатный выход / crash reports | NOT RUN | NOT RUN |

Остаются физический HID/GPU, производительность, доступность памяти, аудио,
полный аппаратный Init и cleanup, единая Campaign/Gov entry и естественная
победа. Следующие исправления — только по пользовательским результатам двух
запусков; аппаратная приёмка не объявлена завершённой.
