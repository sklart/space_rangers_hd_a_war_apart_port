# MatrixGame E610 r39. Преобразование форматов при публикации текстуры

В r38 цикл `native_texture::Publish` узнавал размер и формат выходного пикселя
для каждого элемента. В r39 формат выбирается один раз на mip-уровень.
У каждой специализации фиксирован размер пикселя, а адрес строки вычисляется
до прохода по её пикселям. Преобразование сохраняет альфу в A8R8G8B8,
подставляет 255 в X8R8G8B8 и использует прежние правила квантования для трёх
16-битных форматов. Размеры, размещение уровней и момент публикации определяются
тем же штатным `Publish`.

Базовый исходник r38 — `c45e2604e6c1e24329b72a2e520fe30143a540a7`.
Исходник для сборки r39 — `c1116e01469e443cb5b9fd94ebfee8e3f8845b4d`.

| Формат назначения | r38, мс | r39, мс | Ускорение |
| --- | ---: | ---: | ---: |
| A8R8G8B8 | 213.498 | 125.611 | 1.70× |
| X8R8G8B8 | 216.468 | 121.328 | 1.78× |
| R5G6B5 | 171.799 | 58.365 | 2.94× |
| A1R5G5B5 | 180.326 | 76.008 | 2.37× |
| A4R4G4B4 | 178.435 | 58.302 | 3.06× |

Каждая строка показывает медиану трёх чередующихся запусков. Один запуск
выполняет 48 публикаций на формат. Вход содержит пять уровней RGBA от
1024×1024 и 13 байт заполнения между строками. Время включает выделение
выходных буферов и запись пикселей через штатный `Publish` с пулом системной
памяти. Копия входа и чтение для контрольной суммы выполняются вне отсчёта.
Контрольная сумма выборки из всех выходных уровней во всех замерах —
`7019372761404918755`. Загрузка текстур на GPU и полный Init требуют замера
на Switch.

Host ASan/UBSan, ARM64/QEMU UBSan и Windows O2 проверили по 360 случаев
на r38 и r39. Независимый проверяющий код сверил каждый канал всех уровней.
Сценарии включают автоматический формат, каждый из пяти форматов назначения,
однопиксельные строки и уровни с нечётным шагом. Тест завершается ошибкой
при запросе GPU-выгрузки, а в конце сверяет количество живых дескрипторов.

Первые тестовые запуски выявили ошибки оснастки, включая путь WSL, отсутствующий
объект mip-кода в линковке Windows и инструментированный архив для бенчмарка.
Рабочие результаты получены после исправлений. Линковщик Windows выдал
унаследованное предупреждение LNK4098 о смешанных CRT; оба тестовых процесса
завершились с успешным результатом. Это относится к тестовой оснастке Windows.

Для воспроизведения выполните `python tools/matrixgame_texture_publish_checks.py benchmark`
из корня репозитория. Для проверки каналов используйте `host`, `arm64` или
`windows` вместо `benchmark`. Скрипт использует сохранённые зависимости
проверок E2E521/E2E522 и заново компилирует `native_texture.cpp` двух версий.

Сборка devkitA64 прошла для Quick Smoke и Interactive. Дизассемблирование
обеих ELF подтвердило, что из `Publish` исчез вызов `Layout`. Размер кода
`Publish` в Quick Smoke вырос с 1060 до
1652 байт из-за специализаций. Проверка
неразрешённых сильных символов прошла. Сверены SHA256 729 исходников SDK
и 409 защищённых файлов. Аппаратная проверка имеет статус **HARDWARE PENDING**.
