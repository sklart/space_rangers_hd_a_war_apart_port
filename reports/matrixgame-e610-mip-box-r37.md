# MatrixGame E610 r37. Двумерный BOX-фильтр RGBA

Для построения очередного уровня `TextureAsset::PrepareMips` берёт предыдущий уровень
с размерами, округлёнными до степени двойки. Если обе оси больше единицы, каждый
выходной пиксель соответствует полному входному блоку 2×2. В r37 `FillRGBA`
вычисляет два адреса строк на выходную строку и использует смещения в этих строках.
Каждый канал получает целочисленное среднее `(sum+2)/4`. Вдоль одномерного
хвоста цепочки сохраняется последовательность сложений D3DX с плавающей точкой.

Базовый исходник r36 — `c32f35b8bc4fc8977095a22c34dbf2813f9c14a0`.
Исходник для сборки r37 — `16ecdde1962469dd20eacfee3828f0a1a1f7b400`.

| Операция на host CPU | r36, мс | r37, мс |
| --- | ---: | ---: |
| 64 цепочки BOX из RGBA 512×256, первый замер | 28,844 | 6,702 |
| Те же цепочки, повторный замер | 33,221 | 7,212 |
| 128 расширений до степени двойки, контроль первого замера | 46,057 | 50,021 |
| То же расширение, контроль повторного замера | 49,738 | 44,189 |

Замер использует `-O2` и настоящую `PrepareMips`, включая выделение буферов для
уровней. В таблице медианы трёх запусков в первой серии и пяти в повторной.
Во всех запусках контрольная сумма равна `10909591624186716767`. Разброс
контрольного копирования в двух сериях меняет знак. Измерение даёт примерно
4,6× для цепочек BOX на host CPU. Для расчёта времени загрузки на Switch нужен
аппаратный замер доли этой операции.

Проверки host ASan/UBSan, ARM64/QEMU UBSan и Windows O2 прошли на корпусе r36.
На каждой платформе сравнивались 1928 сценариев, включая 92 отказа и четыре
режима округления. Контрольные суммы полного вывода r36 и r37 совпали на
каждой платформе. 864 отдельных сценария BC с нечётным шагом строки прошли.

Для воспроизведения используйте `python tools/matrixgame_mip_box_checks.py host`,
`arm64`, `windows` или `benchmark` в качестве аргумента. Скрипт использует
архив исходника r36, подготовленный BC.cpp из сборки r36 и свежий каталог для
каждой серии. Для второй серии повторно запускались бинарники первого замера.

Сборка devkitA64 прошла для Quick Smoke и Interactive. Обе ELF содержат
`native_texture::Decode` и `TextureAsset::PrepareMips`. Проверка strong undefined
прошла. Сверены SHA256 728 исходников SDK и 395 защищённых файлов, включая
предыдущие пакеты. Состояние аппаратной проверки — **HARDWARE PENDING**.
