# MatrixGame E610 r38. Gamma-коррекция при копировании RGBA

В r37 подготовка PNG с gamma сначала записывала RGBA-уровень, а затем
перечитывала его целиком для коррекции RGB. В r38 копирование и коррекция
используют один проход по исходным пикселям. Каждый RGB-канал берётся из
прежней таблицы соответствия, а альфа копируется напрямую. Цвет дополнения
до степени двойки корректируется один раз на уровень.

Каждый исходный уровень с gamma проходит через эту операцию. Генерация
последующих уровней использует уже скорректированный предшественник.
Проверки размеров, шага строки и бюджета выполняются до записи в новый
буфер. Публикация цепочки происходит после успешного завершения.

Базовый исходник r37 — `16ecdde1962469dd20eacfee3828f0a1a1f7b400`.
Исходник для сборки r38 — `c45e2604e6c1e24329b72a2e520fe30143a540a7`.

| 128 операций на host CPU | r37, мс | r38, мс |
| --- | ---: | ---: |
| Gamma и дополнение 1023×767 → 1024×1024, шаг исходной строки с 13 байтами заполнения | 273,165 | 94,698 |
| Gamma и полная цепочка BOX 1024×1024 | 386,852 | 223,019 |
| Дополнение без gamma | 41,893 | 41,195 |
| Цепочка BOX 512×256 без gamma | 13,312 | 13,418 |

В таблице медианы пяти повторных запусков на вариант с чередованием
r37/r38. Время измеряет реальную `TextureAsset::PrepareMips` с выделением
выходных буферов. Копия входа создаётся до начала отсчёта.
Контрольная сумма во всех учтённых запусках — `405806661070406423`.
Ускорение составило 2,88× для первого сценария и 1,73× для второго.
Для оценки полной загрузки на Switch нужен аппаратный профиль.

Первый запуск оставил сырые логи, но завершился ошибкой разбора строки.
После исправления сборщик прошёл успешно. В таблицу вошла отдельная
повторная серия из проверенных бинарников второго запуска.

Host ASan/UBSan, ARM64/QEMU UBSan и Windows O2 прошли по 1932 сценария,
включая 92 отказа и четыре режима округления. На каждой платформе
совпали контрольные суммы всего вывода r37 и r38. В каждом режиме
округления добавлен сценарий с двумя исходными уровнями с gamma и
заполнением строк. Независимые проверки сверяют RGB и альфу второго
уровня и его дополнения, затем проверяют BOX-переход к третьему уровню.
Отдельно прошли 864 сценария BC с нечётным шагом строки.

Для воспроизведения измерения выполните команду из корня репозитория.

```text
python tools/matrixgame_mip_box_checks.py benchmark --reference 16ecdde1962469dd20eacfee3828f0a1a1f7b400 --run-name e610-mip-gamma-r38-checks --benchmark-source tests/benchmark_matrixgame_mip_gamma.cpp
```

Для проверки поведения замените `benchmark` на `host`, `arm64` или `windows`.
