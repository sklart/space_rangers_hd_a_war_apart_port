# Журнал изменений

## E2E-5.12 — в разработке

- Сведены изменения веток и старых worktree в `master`; исходные пользовательские `saves/` сохранены.
- В экспериментальном режиме `RSG64/v168` проверены host-процессы ручного сохранения и загрузки, пять ходов после загрузки, новый quicksave и его повторная загрузка. Оба оригинальных предпросмотра в сейве, включая карту галактики, сохранены.
- Повреждённые сохранения отклоняются без падения host; Windows `RSG/v167` отвергается до десериализации. Fault injection транзакции прошёл в host и под ASan/UBSan.
- CI готовит отдельно Save OFF и `save-test-v168` комплекты с NRO, matching ELF, отчётом сборки, provenance и SHA256SUMS. Статус каждого конкретного SHA проверяется в GitHub Actions.

HOST, ARM64/CI и аппаратная Switch-проверка имеют разные статусы. Полный игровой сценарий, аппаратный round-trip сохранений, плавность, фон окон и настоящий планетарный бой MatrixGame остаются открытыми; этот этап не является релизом игры.
